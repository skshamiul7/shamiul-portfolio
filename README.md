# SK Shamiul Islam — Portfolio

A modern, responsive personal portfolio website built with **pure HTML, CSS, and JavaScript** — no frameworks, no build tools, just clean code. Features a dark/light theme toggle, an inline CV viewer, a working contact form (via Netlify Forms), and animated UI elements.

🔗 **Live site:** [https://skshamiul.netlify.app](https://skshamiul.netlify.app)

---

## ✨ Features

- 🌗 **Dark / Light theme toggle** — persists via `localStorage`, follows system preference on first visit
- 🎨 **Modern dark UI** — gradient accents, animated background glow, glassmorphism navbar
- ⚡ **Typing effect** in hero — cycles through roles
- 👤 **Animated profile photo** — conic-gradient rotating ring + pulsing glow
- 📱 **Fully responsive** — mobile-first with a slide-out menu
- 📄 **Inline CV viewer** — embedded PDF with a download button
- 🏆 **Certificates section** — grid of certification cards
- 📬 **Working contact form** — sends submissions straight to my inbox via Netlify Forms
- 🎬 **Scroll reveal animations** — powered by `IntersectionObserver`
- 🧭 **Smooth scrolling** navigation

---

## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| **Markup** | HTML5 |
| **Styling** | CSS3 (custom properties, grid, flexbox, animations) |
| **Scripting** | Vanilla JavaScript (ES6+) |
| **Fonts** | Inter, JetBrains Mono |
| **Forms** | Netlify Forms (AJAX submission) |
| **Deployment** | Netlify |
